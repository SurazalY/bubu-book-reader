# 指标规则与采集上传

> 文档版本：`clean-baseline-metrics-ingest-v1.0`
>
> 时间单位：客户端与服务端内部统一使用整数毫秒；UI 最终按分钟格式化。

## 1. 固定常量

| 常量 | 值 | 边界语义 |
| --- | ---: | --- |
| 统计日切换 | 北京时间 04:00 | 04:00:00.000 属于新统计日 |
| 单次连续有效停留上限 | 300,000 ms | 超出部分不计入 |
| 跳读视图时长 | `< 5,000 ms` | 正好 5,000 ms 不算 |
| 跳读连续视图数 | 至少 2 个 | 必须为正常相邻翻页 |
| 回读距离 | `>= 3` 页 | 正好 3 页满足 |
| 回读目标停留 | `> 30,000 ms` | 正好 30,000 ms 不满足 |
| 每日打卡 | `>= 300,000 ms` | 正好 5 分钟打卡 |
| 上周接近区间 | 正负 10% | 边界按下游测试固定包含关系 |
| 正常累计摘要周期 | 约 5 分钟 | 是上传周期，不是采样周期 |

计算规则：

- 内部时长保持整数毫秒，不先换算为分钟。
- 上周比较使用整数交叉乘法，避免浮点和提前取整改变正负 10% 边界。
- `close`包含正好 -10% 和正好 +10%；超过 +10% 为 `more`，低于 -10% 为 `growth_space`。
- 需要输出平均毫秒时采用四舍五入到最近整数；API 输出整秒时向下取整，UI 再按既定格式显示分钟。

## 2. 阅读视图

- 单页模式：一个页面是一个阅读视图。
- 双页模式：连续左右页共同组成一个阅读视图。
- 只有视图稳定后才开始计时；如果选择性移植旧 E1，沿用其已经验证的稳定视图确认机制。
- 布局变化导致单页与双页转换时，结束旧视图并开始新视图，但不形成学生跳读或回读。
- 页码可用于当前会话判断和上次停留位置，不能写入行为证据表。

## 3. 连续有效停留状态

一个连续停留段至少包含：

- 段开始时间；
- 当前阅读视图；
- 前台状态；
- 书页可见状态；
- 可信亮屏状态（如果运行环境能够提供）；
- 是否已经达到 5 分钟上限；
- 所属统计日；
- 单调时间累计值。

### 3.1 开始

满足以下条件时开始：

- 阅读租约和身份范围有效；
- 阅读视图已经稳定；
- 页面处于前台并可见；
- 可获得亮屏状态时设备处于亮屏；
- 不存在仍在计时的同一段。

### 3.2 结束或切段

以下动作结束当前段：

- 翻页或定位到其他视图；
- 进入后台或页面不可见；
- 关闭阅读器；
- 账号、工作空间、书籍版本或设备范围变化；
- 租约失效或接管；
- 统计日跨越凌晨 4:00；
- 选文、批注、书签、AI 提问等确认的真实操作。

真实操作发生后，如果仍满足阅读条件，可在同一阅读视图开始新段，从而重新获得最多 5 分钟有效时间。

### 3.3 有效时长

```text
有效段时长 = min(真实连续时长, 300,000 ms)
```

- 后台、不可见和已确认熄屏时间为 0。
- 运行环境无法提供可信亮屏事件时，不得常量伪造为亮屏；应在新基线影响审计中记录限制，并以实际可观测的前台/可见性规则实现和验收。
- 同一客户端不能存在两个同时计时的阅读段。
- 跨设备或异常重叠由服务端在权限和会话范围内拒绝或去重，不能重复累计。
- 超过 5 分钟不产生“长停留”业务信号。

## 4. 跳读状态机

维护一个当前快速翻阅连续计数：

1. 只处理学生正常向前或向后翻到相邻阅读视图的移动。
2. 新视图有效展示大于 0 且少于 5 秒时，快速计数加 1。
3. 连续计数达到 2 时，本会话当前统计日 `hadSkip = true`。
4. 任一视图达到 5 秒、定位到非相邻页、恢复位置、教师同步、布局变化、系统恢复、书籍变化或统计日变化时，快速计数重置。
5. `hadSkip` 在同一会话同一统计日内只能从 `false` 变为 `true`。

跨页定位不形成跳读，也不把中间页面逐页补成跳读。

## 5. 回读状态机

1. 只处理学生主动的向前回退。
2. 来源主页面与目标主页面距离达到 3 页时建立回读候选。
3. 目标阅读视图结束时，其累计有效停留超过 30 秒，设置 `hadReread = true`。
4. 正好 30 秒不成立。
5. 教师同步、恢复位置、布局变化和系统恢复不建立候选。
6. 候选中途进入后台后，目标视图的多个有效段可以在同一次访问内累计；离开目标视图后完成判断。
7. 不保留来源页、目标页和目标时长到服务端。

## 6. 统计日边界

- 客户端和服务端必须使用同一个 `statDate` 算法。
- 到达北京时间 04:00 时，先结束当前有效段并提交旧统计日摘要，再结束旧阅读会话。
- 如果阅读器仍然满足条件，使用新的会话 ID 开始新统计日会话。
- 一个会话摘要只属于一个统计日，避免累计总值跨日拆分歧义。
- 服务端校验 `statDate` 与会话开始、测量截止和允许时钟偏差一致。

## 7. 会话累计摘要

### 7.1 租约

- 阅读会话开始前取得现有可信设备阅读租约。
- 租约续期与约 5 分钟摘要上传是两个独立动作。客户端必须根据服务端 `expiresAt`在到期前续期，不能等待摘要上传周期。
- 如果干净基线租约只有约 90 秒且没有续期能力，后端和客户端必须先补正式续期契约。
- 租约续期失败或被接管后，结束当前有效停留，不继续累计新的有效时长。
- 本期没有正式离线授权。租约失效后的新时长不能在重连后冒名绑定到新租约；待确认队列只能重试此前处于合法在线范围的摘要。

### 7.2 摘要范围

每个会话范围固定绑定：

- 组织；
- 学生；
- 工作空间；
- 发生时班级；
- 可信设备；
- 书籍版本；
- 统计日。

累计字段：

- `revision`：从 1 开始严格递增；
- `cumulativeEffectiveMs`：非负、单调不减；
- `hadSkip`：只能 `false → true`；
- `hadReread`：只能 `false → true`；
- `lastPageNo`：最后稳定阅读位置；
- `measuredThroughAt`：累计测量截止时间；
- `endedAt`和结束原因：会话结束时提供。

每个修订使用稳定请求幂等键和稳定摘要指纹。相同修订、相同指纹重放返回已接收结果；相同修订、不同内容必须冲突。

## 8. 上传触发

- 正常阅读累计约 5 分钟；
- 进入后台；
- 关闭阅读器；
- 网络恢复；
- 会话结束；
- 统计日切换；
- 队列达到下游契约规定的安全上限。

普通翻页只更新本地状态，不单独发请求。

## 9. 本地待确认区

- 摘要必须在发请求前原子持久化。
- 按组织、学生、工作空间和可信设备隔离。
- 同一会话只保留尚未确认的必要修订；压缩旧修订时不能破坏服务端严格序列要求。
- 只有服务端明确返回 accepted 或 replayed 的修订才可删除。
- 权限拒绝、租约冲突、范围冲突和数据冲突必须保留并显式报错。
- 本期不承诺离线阅读。网络失败可以重试，但旧租约事实不能冒名绑定到新身份或新租约。

## 10. 服务端接收

单个事务内：

1. 校验身份、组织、工作空间、可信设备、租约、书籍版本、班级快照和统计日。
2. 校验修订顺序、指纹和字段单调性。
3. 读取旧会话累计值。
4. 计算 `deltaEffectiveMs = 新累计值 - 旧累计值`。
5. 更新会话最新修订。
6. 将 delta 增量写入学生每日书籍汇总。
7. 将跳读、回读按逻辑或合并。
8. 更新最后阅读时间和最近位置。
9. 提交事务后返回确认。

任一步失败，事务整体失败，不能出现会话已更新而每日汇总未更新。

## 11. 当前旧链路切换

- 新基线现有 `page_stay/page_turn` 可在新链路验收前保持原功能，但不能与新摘要同时贡献同一套新每日统计。
- 正式切换时确定唯一写入路径。
- 不保留“摘要失败则写旧事件”的备用路径。
- 现有护眼功能如依赖旧事件，必须在影响审计中单独保护，不能因阅读统计切换而破坏。
