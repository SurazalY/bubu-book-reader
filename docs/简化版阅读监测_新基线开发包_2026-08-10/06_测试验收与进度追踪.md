# 测试验收与进度追踪

> 文档版本：`clean-baseline-test-control-v1.0`
>
> 本文件同时提供测试矩阵和主控追踪模板。开发时只更新真实状态，文件存在或开发 Agent 自报不能代替验收。

## 1. 测试层级

### 1.1 纯函数

- 统计日和凌晨 4:00；
- 5 分钟有效时长上限；
- 跳读连续状态；
- 回读距离和时长；
- 打卡边界；
- 上周日均和正负 10%；
- 连续打卡；
- 七日补零；
- 班级打卡率和人均时长。

### 1.2 数据库

- 新基线前向迁移；
- 全新数据库执行；
- 重复启动和校验和；
- 会话范围不可变；
- 修订、累计和布尔单调性；
- 每日唯一键和必要索引；
- 写入事务原子性；
- 账号删除和组织隔离。

### 1.3 服务端领域与 HTTP

- 摘要 accepted/replayed/superseded；
- 租约到期前续期、续期失败、接管和过期摘要拒绝；
- 重复和乱序不重复计时；
- `/self`字段隔离；
- `/scope`班级汇总、趋势和学生数组；
- 教师权限、学生权限和跨校拒绝；
- 转班发生时班级快照；
- 请求 ID 和错误 envelope。

### 1.4 前端状态和组件

- 阅读器连续停留与行为状态机；
- 本地待确认区和恢复；
- 学生简报状态和文案；
- 继续阅读跳转；
- 教师轮询、手动刷新、筛选和抽屉；
- 权限失败和网络错误不伪装成功。

### 1.5 集成和浏览器

- 学生阅读 → 上传 → 每日简报；
- 学生阅读 → 教师 5 分钟内查询；
- 重复提交；
- 后台/恢复；
- 账号切换；
- 教师筛选和学生抽屉；
- 1024×768 和桌面尺寸；
- 旧复杂功能不存在。

## 2. 关键边界用例

### 2.1 有效阅读

| 场景 | 预期 |
| --- | --- |
| 前台可见 4:59 | 累计 4:59 |
| 前台可见 5:00 | 累计 5:00 |
| 无交互停留 8:00 | 只累计 5:00 |
| 5:00 后真实批注，再读 2:00 | 累计 7:00 |
| 进入后台 3:00 | 后台时间为 0 |
| 两个重叠修订重放 | 每日汇总不增加第二次 |

### 2.2 跳读

| 场景 | 预期 |
| --- | --- |
| 单个相邻视图 4.999 秒 | 不足连续 2 个，不触发 |
| 连续两个相邻视图各 4.999 秒 | `hadSkip=true` |
| 第二个视图正好 5 秒 | 不触发 |
| 从第 1 页定位第 80 页 | 不触发 |
| 恢复上次位置 | 不触发 |
| 教师同步连续翻页 | 不触发 |
| 双页视图停留 4 秒 | 只算一个快速视图 |

### 2.3 回读

| 场景 | 预期 |
| --- | --- |
| 回退 2 页停留 31 秒 | 不触发 |
| 回退 3 页停留正好 30 秒 | 不触发 |
| 回退 3 页停留 30.001 秒 | `hadReread=true` |
| 教师同步向前 5 页停留 60 秒 | 不触发 |
| 恢复位置向前 10 页 | 不触发 |

### 2.4 打卡与连续天数

| 场景 | 预期 |
| --- | --- |
| 今日 299 秒 | 未打卡 |
| 今日 300 秒 | 已打卡 |
| 今天尚未打卡、昨天之前连续 5 天 | 显示连续 5 天，今日未完成 |
| 昨天未打卡 | 连续 0 天 |
| 跨周连续 | 不清零 |

### 2.5 上周比较

- 上周 7 天缺失日期按 0；
- 上周总值 0 → `no_baseline`；
- 正负 10%边界有明确测试；
- 学生响应不出现具体上周字段；
- 教师响应包含上周总值、日均和今日差值。

### 2.6 阅读位置

- 普通阅读更新上次停留页；
- 回读后可更新当前停留页；
- 直接跳到最后一页不会将书标记为完成；
- 学生简报继续阅读打开正确版本和页码；
- 旧“全部读到最后一页”统计不再出现。

## 3. API 契约反例

- 相同修订、相同指纹：replayed；
- 相同修订、不同指纹：冲突；
- 修订跳号：拒绝；
- 累计时长下降：拒绝；
- `hadSkip true→false`：拒绝；
- 书籍、账号、设备、统计日范围变化：拒绝；
- 未来时间：拒绝；
- 无租约或租约冲突：拒绝；
- 跨校教师：拒绝；
- 学生请求教师 scope：拒绝；
- 删除后本人数据不可读取；
- 错误响应仍包含请求 ID。

## 4. 班级与容量数据集

至少准备：

- 50 名有效学生；
- 37 名达到 5 分钟；
- 若干 0 秒和不足 5 分钟学生；
- 4 名跳读、8 名回读；
- 完整 7 个统计日并包含零值日期；
- 多本书；
- 一个无上周基线学生；
- 一个今日未打卡但昨天仍有连续记录学生。

验算：

- 打卡率 37/50；
- 人均时长包含全部 50 人；
- 未打卡筛选同时包含 0 秒和不足 5 分钟；
- 默认列表不按时长排序；
- 趋势恰好 7 个点。

## 5. 基线与回归命令

主控先读取新基线 `package.json`和现有测试脚本，再记录真实命令。不得假设旧工作区命令完全一致。

至少覆盖：

- 服务端真全量测试；
- 前端真全量测试；
- 生产构建；
- 数据库迁移测试；
- 阅读专项测试；
- API 集成测试；
- 浏览器关键流程。

如果使用现有旧工作区经验，服务端曾需要同时包含根级和递归测试文件；新基线应通过实际文件清单确认，不能只运行会漏测的 glob。

## 8. Agent 协作规则

- 主控亲自负责权威文件和最终整合。
- 子 Agent 只接收范围清晰、文件不重叠的任务。
- 数据迁移和核心领域写入保持单一写入者。
- 前端可以在 API 契约冻结后工作，不在字段未定时发明兼容逻辑。
- 减少重复多轮审查，但保留后端实现审查、前端实现审查和最终联合验收。
- 未经用户授权不执行 Git 写操作。
