## 2. 控制原则

### 2.1 状态定义

| 状态 | 含义 |
| --- | --- |
| ⬜ `pending` | 依赖尚未满足，不能开工 |
| 🟦 `ready` | 依赖和文件所有权已经明确，可以开工 |
| 🟨 `in_progress` | 唯一负责人正在实施 |
| 🟪 `implemented_unverified` | 实现者自测通过，尚未经过约定验收窗口 |
| 🟥 `blocked` | 存在明确阻塞，负责人不能继续推进 |
| ✅ `completed` | 约定测试、审查和验收证据均已满足 |

不得因为文件已经存在、实现者自报完成或局部测试通过而直接标记 `completed`。

### 2.2 文档写入规则

- 本文件只由主控 Agent 修改。
- 子 Agent 不直接修改进度表，只向主控回报任务状态、文件清单、命令、结果和风险。
- 主控只在任务状态变化、发生阻塞、完成一次交接或通过门禁时更新，不按每个小文件频繁记录。
- 需求包保持只读，不把实时进度写回解压目录。

### 2.3 Git 规则

- 当前用户未授权暂存、提交、推送、删除远端分支或切换到其他分支。
- 主控和子 Agent 不执行 `git add`、`git commit`、`git push`、破坏性重置或清理。
- 子 Agent 不切换分支，不创建个人分支，不改远端。
- 需要发布阶段成果时，由用户另行授权，主控统一处理。

## 4. 已确认的源码影响

| 现状 | 新需求影响 | 初步决议 |
| --- | --- | --- |
| 客户端硬编码 `screenOn: true` | 不符合可信亮屏要求 | 新摘要不发送该字段；旧护眼事件只以文档可见性为代理，不声称物理亮屏 |
| 阅读租约默认 90 秒 | 约 5 分钟摘要周期不能覆盖租约寿命 | 增加明确续租契约，客户端按 `expiresAt` 提前续租 |
| 客户端上传 `page_stay/page_turn` | 新真值是会话累计摘要 | 新链路验收前保留旧功能；正式切换时禁止双写新统计 |
| 旧阅读事件同时支持护眼 | 不能因新统计切换破坏护眼 | 在 G1 冻结“统计写入”和“护眼输入”的边界 |
| 现有统计从逐页事件查询派生 | 不符合新每日汇总模型 | 新增 `043`、会话摘要和每日书籍汇总查询 |
| 服务端投影、两个 adapter、Reader 和多个页面以页码计算百分比或 `finished` | 最后页只能表示停留位置 | C 清理 Reader；I 串行统一清理其余共享消费者和 AI/报告覆盖推断 |
| 教师旧统计包含异常停留等字段 | 新版只保留轻量事实 | 新接口和页面不继续携带旧复杂字段 |
| 新 `/self`、`/scope` DTO 与旧消费者不兼容 | 缺字段补 0 会把错误伪装成成功 | 严格替换 DTO；I 显式迁移或删除全部旧消费块，不保留旧兜底 |
| 前端测试全局禁止 IndexedDB | 与请求前原子持久化硬需求冲突 | 只精确放行 `pendingStore.js`，继续禁止其他业务存储 |

## 5. 并发模型和角色

### 5.1 并发上限

并发槽以运行环境实际报告为准。当前按以下安全上限规划：

- 1 个主控 Agent；
- 最多 3 个同时运行的子 Agent；
- 若需要新的独立审查 Agent，优先在某个开发 Agent 完成交接后复用并发槽；
- 用户可见的新线程不是普通子任务的默认方案，只有用户明确授权且任务确实需要独立生命周期时才使用。

即使未来环境允许更多并发，也不得增加迁移、核心领域、共享路由或共享页面的并行写入者。额外并发只用于只读审计、测试设计和独立复核。

## 8. 验收策略

本项目不在每个小阶段进行完整验收。采用“两次轻门禁、一次视觉检查、一次正式验收”，日常局部测试属于实现者自测。

### AV-0：G0/G1 开工门禁

**时机：** 任何生产代码修改前。

**性质：** 轻量门禁，不做完整功能验收。

**执行者：** 主控整理证据；验收 Agent V 可独立抽查。

**范围：**

- 正式 v3 身份、分支、HEAD 和干净状态；
- 迁移账本与下一个编号；
- 真实安装、全量测试、构建和浏览器冒烟；
- 旧复杂分析污染检查；
- 租约、护眼、旧事件与新真值的边界决议；
- 文件所有权与并行任务依赖。

**通过条件：** G0/G1 所有阻塞项有明确结论，生产任务由 `pending` 转为 `ready`。

### AV-1：关键纵向链路验收

**时机：** 后端摘要写入和客户端核心链路均达到 `implemented_unverified`，页面可以尚未完成。

**性质：** 半天内完成的聚焦验收，不跑所有 UI 细节。

**执行者：** 独立验收 Agent V；实现者只负责复现环境和修复。

**必须验证：**

1. 学生阅读产生累计摘要；
2. 摘要 `accepted/replayed/superseded` 语义正确；
3. 重复、乱序、倒退和冲突不重复计时；
4. 服务端同事务更新会话与每日书籍汇总；
5. 租约续期成功、失败、接管和过期后停止新增时长；
6. 前后台切换与凌晨 4:00 切日正确；
7. 学生 `/self` 和教师 `/scope` 返回冻结契约；
8. 跨校、跨主体和无权限请求明确失败；
9. 新旧链路不同时贡献新统计；
10. 护眼既有功能没有被新统计切换破坏。

**通过后的动作：**
