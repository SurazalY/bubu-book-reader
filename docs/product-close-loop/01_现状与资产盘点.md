# 01 现状与资产盘点

盘点时间：2026-08-17。基于对 `server/`、`src/`、`docs/`、`book-parser/` 与数据目录的全面探查。执行者可信任本文件结论，但动手改某个模块前仍应先读对应源码确认细节。

## 1. 技术栈与结构

- 前端：React 18 + Vite + Tailwind，`src/` 分三套壳：`src/student/`（学生端）、`src/console/`（教师/学校/平台端）、`src/pages/`（营销站+已退役演示，勿当产品入口）。API 封装在 `src/api/client.js`（`/api/v1`、Cookie、`X-Workspace-Id`、写请求 `Idempotency-Key`），DTO 适配在 `src/adapters/`。
- 后端：Express（`server/app.js` 工厂，`server/index.js` 入口），SQLite 用 Node 内置 `node:sqlite` 的 `DatabaseSync`（`server/db/database.js`），迁移 `server/db/migrations/000–044` 启动时自动跑。业务路由集中在 `server/http/integration-router.js`（约 80 条），身份在 `server/domains/identity/`。
- 认证：用户名+密码 → HttpOnly Cookie（`readmate_session`）；权限 = workspace 成员资格 + `role_assignments` 按动作表授权（`server/domains/identity/permissions.js`）。角色要点：`student`、`teacher/class_teacher`（无 `book.publish`）、`school_admin`（有 `book.import`+`book.publish`+`book.archive`）、`platform_ops`。
- 静态资产：书籍资产一律走受保护接口 `GET /api/v1/books/assets/:assetId`（Range、MIME、size 校验）；公开 `/books/*` 已被故意 404。`storage_key` 必须是相对键，运行时根为 `PUBLIC_ASSET_DIR`（默认 `public/`）。
- 测试：`tests/server/`（node --test，约 27 个文件）、`tests/frontend/`（契约/源码扫描型 .mjs）。当前基线全绿（上轮记录：server 173/173，frontend 162/162）。

## 2. 能力状态矩阵（核心结论）

| 能力 | 状态 | 说明与关键文件 |
|---|---|---|
| 书目数据模型（books/book_versions/book_pages/book_blocks/book_assets） | ✅ 可直接沿用 | `server/db/migrations/010_reading_catalog.sql`、`044_reader_dual_mode_pilot.sql`。物理页是唯一页码；044 已给页/块加 raw/normalized 文本、可空印刷页标签、audit-only 几何 |
| book-package/v2 导入器（整本 PDF + 按页 OCR 文本） | ⚠️ 需要改造 | `server/db/import-book-package-v2.js`。功能完整（结构/哈希/PDF页数校验、幂等、审计），但**强制人工质检闸门**（`quality.status` 与人工复核必须 `passed`，否则 `HUMAN_REVIEW_REQUIRED`）——与新基线冲突，需按决策 D1 增加 trusted 模式。不注册封面资产，需补 |
| v2 打包器 | ⚠️ 需要新适配 | `book-parser/pipeline/build_book_package_v2.py` 消费的是 `text-ocr-v1` 的 JSON 页（带几何），**不是** antigravity 纯 txt；且依赖 `pilot-books.json`/report/prompt。需要新写 antigravity → v2 包的打包器（决策 D1） |
| 学生书架 + 服务端可见性过滤 | ✅ 沿用（组织级） | `src/student/pages/Shelf.jsx`、`server/domains/reading/catalog.js` `listBooks`：本组织 + `status='published'` 全员可见。班级过滤不存在，见下行 |
| 班级/学生可见范围 | ❌ 未实现 | `book_access_grants` 表（`book_version_id, grantee_type, grantee_id`）在 010 建了但**代码零引用**。"阅读安排"（assignments）只是布置作业，不控制书架可见性 |
| 发布/取消发布 HTTP + UI | ❌ 未实现 | 领域函数 `publishBook()` 在 `catalog.js`（且要求 `package_quality_status='passed'`，需随 D1 放宽），无 HTTP 端点、无教师端 UI。教师端书库 `src/console/pages/teaching/BookLibrary.jsx`/`BookDetail.jsx` 只读 |
| 双模式 Reader（学生端） | ✅ 基本沿用 | `src/student/pages/Reader.jsx`：`readerMode='original'|'text'`，切换不改 `pageNo`；原版用 `src/student/components/PdfBookPage.jsx`（pdfjs-dist 6.2.108，受保护资产加载，页数校验，只渲染当前±2 页，加载失败不自动切文字模式）；文字模式按物理页拉 `GET /books/:bookId/pages/:pageNo` 的 normalizedText+blocks 渲染可选择 DOM。**缺**：模式不持久化（刷新后有 PDF 就回原版）、空页显示"服务端返回了空页"而非空白页状态 |
| 页码/进度体系 | ✅ 沿用 | 权威坐标 `bookVersionId + physicalPageNo`（从 1 起）。进度在服务端 `reading_progress.last_page_no`（来源是计时会话摘要）。Reader 打开逻辑 `src/student/reading-monitor/view.js` `resolveReaderLocation`（query 只认 `versionId`/`pageNo`）。**已知 bug**：`src/student/pages/Highlights.jsx` 摘录跳转用了 `?page=`，解析器不认 |
| 文本选择 + AI | ✅ 沿用 | `src/student/hooks/useReaderGesture.js`（长按/Ctrl 拖自建选区，锚点 pageNo+blockId+偏移）→ `AiPanel.jsx` → `POST /ai/messages`（带 `bookId, currentPageNo, readRangeVersion, selections[]`）。服务端从 normalized_text 重建选文；AI 可读范围 = 已覆盖页 ∪ 当前页；引用带页码、可 `onJumpPage` 跳回。仅文字模式可选文（符合要求） |
| 阅读计时系统 | ✅ 完成品，沿用 | 服务端 `server/domains/reading/monitoring.js` + `statistics.js` + 迁移 043；前端 `src/student/reading-monitor/**`（coordinator 单一状态机）+ `useReadingTelemetry.js` 已挂学生 Reader。租约 90s（`POST /reading/lease`、`/renew`），主计时入口 `POST /reading/session-summaries`（累计摘要+revision+指纹），已按 `effectiveOriginalMs`/`effectiveTextMs` 区分双模式逐页覆盖（`reading_page_coverage`）。清理脚本 `npm run maintenance:reading-monitor-cleanup`。该系统 2026-08-11 已整体通过 AV-2 验收 |
| 学生每日简报 / 教师班级统计 | ✅ 沿用 | 学生 `GET /reading/statistics/self` → `src/student/.../DailyReadingBrief.jsx`（Home 顶部卡）；教师 `GET /reading/statistics/scope?classId=&statDate=` → `src/console/pages/classes/ClassOverview.jsx`。统计日北京时间 04:00 切，打卡阈值 300s |
| 学生端退出登录 | ❌ 未实现 | 设置页未挂路由，不调 `POST /auth/logout`。教师端 TopBar 有正规退出 |
| 教师端阅读器 | 维持现状（决策 D10） | `TeacherReader.jsx` 纯文字，无双模式无计时，本期不动 |
| 旧事件流 `POST /reading/events/batch` | 保留但只喂护眼 | `valid_reading_seconds` 恒 0，**不得**用作阅读时长来源 |
