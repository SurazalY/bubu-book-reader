# 一体化领域、API、权限与审计契约

> 状态：Stage 1 冻结稿。具体阈值只采用主线已拍板值；供应商、密钥、正式域名和外部账号不进入仓库。

## 1. 技术边界

- 保留 React/Vite 前端与 Express 服务入口，新增 `/api/v1` 真实业务接口。
- 演示与本地联调使用持久化 SQLite 数据库；数据库访问封装在仓储层，SQL 迁移按领域拆分，避免页面直接读文件或 fixture。正式部署可在保持 API/领域契约的前提下迁移 PostgreSQL。
- 会话认证使用服务端会话和 HttpOnly Cookie；前端选择工作空间只改变请求上下文，服务端每次重新验证成员关系、动作和数据范围。
- 所有 ID 使用稳定 UUID/ULID；时间持久化为 UTC，护眼与配额日/周窗口按 `Asia/Shanghai` 凌晨 4:00 计算。
- 所有写请求必须支持 `Idempotency-Key`，服务端保存请求摘要与结果，重试不得重复写入、扣量或广播。

## 2. 核心数据实体

| 领域 | 实体 | 关键约束 |
|---|---|---|
| 组织账号 | `organizations`、`users`、`credentials`、`sessions`、`role_assignments`、`classes`、`class_memberships` | 停用不删历史；误建且无业务记录才可硬删除；角色绑定 `scope_type/scope_id` |
| 设备空间 | `trusted_devices`、`active_reading_leases`、`workspace_preferences` | 学生多可信设备但同一时刻仅一台当前阅读设备；管理端课堂仅一台控制端 |
| 书籍阅读 | `books`、`book_versions`、`book_pages`、`book_blocks`、`book_assets`、`book_access_grants`、`reading_events`、`reading_sessions`、`reading_progress`、`reading_policy_versions` | PDF/EPUB 保留页序、比例、图片和文字坐标；下架后历史引用转隐藏证据快照；有效阅读与有效用眼分别由服务端计算 |
| 教学课堂 | `reading_assignments`、`assignment_classes`、`class_sessions`、`class_session_clients`、`class_broadcasts` | 一次安排覆盖多班；课堂只锁书、同步页；AI 一次调用后广播同一结果 |
| 阅读成果 | `bookmarks`、`highlights`、`annotations`、`excerpt_collections` | 引用保存书籍版本、页、段落、字符范围和产生时组织快照 |
| AI 与索引 | `ai_conversations`、`ai_messages`、`ai_message_evidence`、`ai_usage_ledger`、`book_index_jobs`、`book_memory_cards` | 消息正文与引用/隐私/危险字段原子落库；索引只覆盖有效已读页面集合 |
| 隐私安全 | `privacy_access_requests`、`safety_review_tasks`、`safety_events`、`safety_event_evidence`、`safety_implicated_candidates`、`safety_handlers` | 误报留痕关闭；复核失败转人工确认；涉事排除由后端组织链计算 |
| 社区报告 | `community_posts`、`post_assets`、`post_reviews`、`post_reactions`、`reports`、`report_versions`、`parent_contacts`、`report_deliveries`、`delivery_receipts` | 无评论/私聊/关注；发送状态与打开/已读状态分离，纯短信不伪造打开状态 |
| 外部桥接 | `integration_clients`、`integration_launch_tokens`、`integration_launches` | 只保存读伴侧桥接记录；短期签名令牌防重放，不复制电子书包主项目代码或业务表 |
| 可靠性审计 | `audit_events`、`idempotency_records`、`outbox_events`、`job_runs` | 审计追加写不可覆盖；外部发送与广播走 outbox，可重试可追踪 |

所有业务表至少包含 `id`、`created_at`、`updated_at`、`version`；需要历史归属的记录同时保存 `organization_id_at_creation`、`actor_id_at_creation` 与必要显示快照。个人敏感数据不进入普通技术日志。

## 3. API 通用结构

成功：

```json
{
  "data": {},
  "meta": {
    "requestId": "req_...",
    "serverTime": "2026-08-05T10:00:00.000Z",
    "nextCursor": null
  }
}
```

失败：

```json
{
  "error": {
    "code": "PERMISSION_DENIED",
    "message": "当前工作空间无权执行此操作",
    "retryable": false,
    "details": {},
    "requestId": "req_..."
  }
}
```

- 列表统一 `limit`（默认 20、最大 100）与游标分页，不用页码推导实时数据。
- 受保护接口读取 `X-Workspace-Id`，并与服务端会话中的可用工作空间集合核对。
- 资源版本使用 `ETag/If-Match` 或请求体 `version`，冲突返回 `409 VERSION_CONFLICT`。
- 常用错误码固定为 `AUTH_REQUIRED`、`SESSION_EXPIRED`、`PERMISSION_DENIED`、`RESOURCE_NOT_FOUND`、`VALIDATION_FAILED`、`VERSION_CONFLICT`、`IDEMPOTENCY_CONFLICT`、`RATE_LIMITED`、`DEPENDENCY_UNAVAILABLE`、`HUMAN_REVIEW_REQUIRED`。

## 4. 第一阶段真实 API 面

| 分组 | 接口 | 真实结果 |
|---|---|---|
| 认证空间 | `POST /api/v1/auth/login`、`POST /auth/logout`、`GET /session`、`GET /workspaces` | 真实账号登录、会话、可用工作空间和恢复路由 |
| 组织班级 | `/organizations`、`/users`、`/classes`、`/classes/:id/members` | 创建/停用账号、班级关系、按范围下钻 |
| 书籍阅读 | `/books`、`/books/imports`、`/books/:id/pages/:pageNo`、`/reading/leases`、`/reading/events/batch`、`/reading/progress`、`/eyecare/status` | 导入、分页原文、唯一阅读设备、幂等补传、有效阅读/用眼分算与服务端校正 |
| 安排课堂 | `/assignments`、`/class-sessions`、`/class-sessions/:id/page`、`/class-sessions/:id/broadcasts` | 多班安排、唯一控制端、锁书/同步页、单次 AI 广播 |
| AI 会话 | `/ai/conversations`、`/ai/messages`、`/ai/messages/:id` | 多会话、可信原文检索、引用、用量与结构化安全字段 |
| 隐私安全 | `/privacy-access-requests`、`/safety/reviews`、`/safety/events`、`/safety/events/:id/accept` | 私密申请、二次复核、回避链、用途登记和处理留痕 |
| 社区报告 | `/community/posts`、`/community/reviews`、`/reports`、`/reports/:id/versions`、`/deliveries`、`/receipts` | 投稿审核、报告版本、发送重试与真实回执 |
| 电子书包桥接 | `/integrations/schoolbag/tokens/verify`、`/integrations/schoolbag/launch-context`、`/integrations/schoolbag/return` | 验证短期签名、防重放和目标权限，只返回书籍/页面/课堂/返回地址契约 |
| 审计运营 | `/audit-events`、`/usage/summary`、`/health` | 范围内审计、Token/成本、依赖健康，不暴露密钥 |

前端不得直接传任意原文给 AI 作为可信证据。请求只提交 `bookVersionId/pageNo/blockIds/selectionRange/readRangeVersion`；后端读取书库正文、校验已读范围并生成证据块。

阅读事件至少包含稳定事件 ID、设备 ID、书籍版本、页面、事件类型、客户端发生时间、前台/亮屏状态和离线序号；服务端按唯一 ID 幂等去重并重算有效阅读与有效用眼。日、周窗口按东八区凌晨 4:00 重置，连续用眼不因登录、换机或跨重置点清零。

电子书包桥接令牌只承载 `issuer/audience/subject/bookId/pageNo/classSessionId/returnUri/issuedAt/expiresAt/nonce` 等最小字段；读伴后端校验签名、受众、过期、重放和目标权限。仓库只实现桥接契约、模拟器和转交材料，不导入 `bubu-prototype-design` 的主业务代码。

## 5. 权限模型

工作空间代码沿用前端壳：`class-teacher`、`grade-group`、`grade-admin`、`school-admin`、`platform-ops`。它们是同一账号的授权视图，不是前端伪切角色。

服务端授权判定为：`会话有效 ∧ 用户未停用 ∧ 工作空间成员关系有效 ∧ 动作允许 ∧ 资源落在 scope 内 ∧ 特殊回避/隐私条件允许`。默认拒绝，公共接口显式白名单。

| 动作族 | 代表动作 | 范围规则 |
|---|---|---|
| 账号班级 | `account.read/manage`、`class.read/manage` | `own/class/grade/school/platform`，校长书记无直属班级入口但可从组织总览下钻 |
| 书籍教学 | `book.read/import/publish/archive`、`assignment.manage`、`classroom.control`、`integration.launch/return` | 教师只管理授权班级；导入/下架需要管理员叠加权限；课堂控制端唯一；桥接目标仍按真实学生/课堂权限校验 |
| 阅读会话 | `reading.read_self/read_scope`、`conversation.read`、`privacy.request` | 学生看本人完整历史；普通会话按范围查看并审计；私密会话走申请 |
| 安全处置 | `safety.review/accept/transfer/close` | 安全∩私密时处理权限优先，但仅最小必要上下文；涉事人员不可见、不可处理 |
| 社区报告 | `community.submit/moderate`、`report.generate/review/send` | 学生投稿；教师/学校按范围审核；发送规则由学校配置 |
| 平台运营 | `policy.manage`、`model.manage`、`audit.read_platform` | 只维护平台边界和跨校运营，不伪装学校业务操作者 |

## 6. AI、隐私与危险状态机

每条 AI 回复只有在 `answer`、引用、用量、`privacy` 和 `danger` 全部校验后才提交并显示逐字动画。普通失败不写假答案，返回可理解的重试状态。

- 隐私/危险聚合按同一会话中 `confidence >= 配置阈值` 的绝对消息数，不按占比；初始建议阈值 `0.8`，默认 `3` 条，学校可在平台允许的 `3～5` 条内配置。
- 单条明确自伤计划、时间、手段或极高危置信度启用紧急旁路，立即创建二次复核任务，不等待累计三条。
- 紧急旁路和普通命中都不能绕过复核直接发布正式事件；误报创建事件后标记 `false_positive_closed`，复核失败/超时/解析失败创建 `pending_human_confirmation`。
- 模型只能从后端候选表返回稳定 `candidate_user_id`；后端根据组织链、学校配置和账号关系计算通知人并排除涉事候选。无法唯一匹配时跳过可能涉事的直接教师层并要求人工确认。
- 额度耗尽不得阻止安全回应、二次复核和事件生成；系统安全任务不扣学生个人额度，但计入学校系统保底池。

## 7. 审计契约

以下事件必须追加写入 `audit_events`：登录成功/失败/退出、工作空间使用、账号与权限变更、书籍导入/发布/下架、阅读安排变更、课堂控制权与广播、会话查看、隐私申请/批准/超时、AI 逻辑请求与模型切换、危险复核、事件接手/转交/升级/关闭、社区审核、报告生成/审核/发送/重试、家长回执、电子书包令牌签发/校验/拒绝。

审计记录至少包含 `event_type`、`actor_user_id`、`workspace_id`、`scope_snapshot`、`resource_type/id`、`request_id`、`idempotency_key`、`outcome`、`reason_code`、`before_version/after_version`、`created_at`。敏感正文只保存受控证据引用，不复制进通用审计 payload。

## 8. 测试账号与数据规则

- 测试数据通过版本化 seed/导入命令生成，账号、组织、班级、书籍和关系真实落库；前端不携带 fixtures 作为最终运行数据源。
- 至少准备学生、班级教师、教研协作、年级管理、学校管理、平台运营六种真实登录状态；“五类工作空间”与学生端账号分开理解。
- 账号名、手机号、家长联系人和书籍材料全部脱敏或获授权；密码只通过运行时参数/环境注入，seed 文件只保留不可逆哈希或占位符。
- 每条演示主链有前置数据、操作步骤、客户端截图、服务端记录、数据库结果、失败分支、重试结果和清理命令。
