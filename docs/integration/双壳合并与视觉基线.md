## 不可破坏项

- 两端共享同一张书香晨光背景，但学生端更暖、更低信息密度，权限端更克制、更高信息密度。
- 学生端底部四项导航、固定排版书页、可选择文字、绿色已读与淡粉未读轨道、轨道内部蓝色书签不得改变。
- 权限端左侧一级栏、按需二级栏、右上常驻头像/工作空间浮层、景观首页和右侧会话三级索引不得重排。
- 玻璃层级、圆角、字体、主要色调、卡片结构、单次扫光和减少动态效果保持原实现。
- 真实加载、空、错、断网、权限拒绝和重试状态优先嵌入现有卡片或浮层；确需改变布局层级先回主线。

## 复核顺序与降级

1. 先读取组件、样式和设计变量，保存目标状态截图及哈希。
2. 只改当前链路需要的最小 DOM、状态和适配层，不新增全局覆盖 CSS。
3. 在相同路由、视口和数据状态重拍，检查悬浮、展开、选文、动效与减少动态效果。
4. 首选现有浏览器检查链路；失败时切换 Playwright/Edge 或可用的应用内浏览器，保留命令、错误和未覆盖范围，不能以“代码看着一致”代替截图。
